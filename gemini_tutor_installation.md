Here are the instructions for anyone who wants to know how to properly install my API-powered Gemini tutoring program, built with Python!

1. Make sure the latest version of Python (3.14.6 as of 7/28/2026) is installed on your machine.
Python download link: https://www.python.org/downloads/
Additionally, you can verify your version by running the following command in your system's terminal: python --version

2. Install the required library for the program to run properly by running the following command in your system's terminal: pip install google-genai

3. Grab an API key for Gemini from Google AI Studio (do NOT share this or use this in code publicly released)!
Keep in mind, you WILL need to verify your age to get an API key!
Google AI Studio: https://aistudio.google.com/welcome

4. Set up your API key to connect with Python before running the program.
Input one of the following commands (based on your device/operating system) into your system's terminal:
- For Mac/Linux: export GEMINI_API_KEY=your_api_key_here
- For Windows (via Command Prompt): set GEMINI_API_KEY=your_api_key_here
- For Windows (via PowerShell): $env:GEMINI_API_KEY=your_api_key_here

5. Download the raw script file from GitHub. You can navigate to the GitHub script view, click the Raw button to view the raw Python code, and save it locally as socratic_tutor_ai.py.

6. Run the program using Python via your system's terminal using the following command: python socratic_tutor_ai.py

7. Have fun, run wild!
